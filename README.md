# Sonar Rock vs Mine Prediction App

This project is a Machine Learning web application built using Streamlit.

The model predicts whether the object detected by sonar signals is:
- Rock
- Mine

---

## Features

- Simple Streamlit web interface
- Predicts Rock or Mine using sonar signal values
- Fast and lightweight application

---

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- NumPy
- Pandas
